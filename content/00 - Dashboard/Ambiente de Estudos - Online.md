# 💻 Como Praticar (IDEs Online Gratuitas)

Junior, você não precisa de uma super máquina para rodar o **FinanceiraEstude**. Aqui estão as melhores formas de praticar sem instalar nada localmente.

---

## 🚀 1. GitHub Codespaces (Recomendado para o Projeto Completo)
Esta é a forma mais profissional. O GitHub te dá um computador na nuvem com VS Code e .NET instalado.

1.  Vá até o seu repositório no GitHub.
2.  Clique no botão verde **"<> Code"**.
3.  Selecione a aba **"Codespaces"**.
4.  Clique em **"Create codespace on v4"**.
5.  **Pronto!** Em 1 minuto você terá um VS Code completo no navegador. 
    - No terminal do Codespaces, digite: `dotnet run --project FinanceiraEstude.API` para ver a mágica acontecer.

## ⚡ 2. DotNetFiddle (Para Testes Rápidos de Lógica)
Se você quer apenas testar um algoritmo, uma query LINQ ou um pequeno método:
- Acesse: **[dotnetfiddle.net](https://dotnetfiddle.net/)**
- Cole o código da lição.
- Clique em **Run**.
- Ideal para os módulos de **Fundamentos** e **LINQ**.

## 🛢️ 3. SQL Fiddle (Para Treinar o Banco)
Para testar as queries do Módulo 06:
- Acesse: **[sqlfiddle.com](http://sqlfiddle.com/)**
- Escolha **PostgreSQL** ou **MS SQL Server**.
- Cole o esquema da tabela e faça suas consultas.
