## 🎮 Prática: Side Quest (Engenharia Reversa)
Escolha uma página web complexa (ex: Github ou um Dashboard administrativo). 
1. Abra o Console do Chrome (F12) -> aba Network.
2. Identifique uma das chamadas da API (XHR/Fetch) e copie o JSON da resposta.
3. Peça para a IA: "Gere as classes C# (Entidade e DTO) que representem esse JSON, seguindo as regras de DDD e Clean Architecture."

## 📜 XP Check (10 Questões de IA e Carreira)

1. **(Engenharia)** O que significa o conceito de "Context Window" em uma conversa com a IA?
2. **(IA)** Por que referenciar um arquivo existente no seu prompt (ex: "Siga o padrão do arquivo X") melhora o resultado?
3. **(Prompts)** Qual a diferença entre um prompt genérico e um prompt estruturado?
4. **(Carreira)** A IA substitui a necessidade de aprender lógica de programação? Justifique.
5. **(Segurança)** Qual o perigo de colar segredos (`API Keys`, senhas) em chats de IA públicos como o ChatGPT?
6. **(IA)** O que é uma "Alucinação" da IA e como você pode validar se o código gerado é real ou inventado?
7. **(Workflow)** Como a IA pode ajudar na criação de Testes Unitários para um código que você já escreveu?
8. **(Reverse Engineering)** Como o uso da aba "Network" do navegador ajuda a dar contexto para a IA sobre um sistema legado?
9. **(IA)** O que é o "Zero-Shot Prompting" vs "Few-Shot Prompting"? (Dica: Dar ou não exemplos no prompt).
10. **(Carreira)** Como você usaria a IA para simular uma entrevista técnica de emprego para uma vaga Sênior?
